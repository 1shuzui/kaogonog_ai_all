# 分类逻辑修改指导提示词

本文档用于指导后续修改题库、套题、定向备面、全真模拟等功能中的“考试分类逻辑”。本文只描述分类原则、层级结构、识别口径和异常处理方式，不限定具体接口、数据库表或前端实现。

参考资料来自本目录下的 PDF 与图片文件，包括国考、省级公务员、事业单位、银行、医疗、法检等分类架构图。由于部分 PDF 为图片型内容、部分 JPG 为手写或低清图，本文对不够明确的部分采用保守归纳，并在“资料不明确之处”中单独说明。

## 一、修改目标

将现有分类逻辑从“简单省份/岗位/题型匹配”升级为“考试体系层级分类”。

核心目标如下：

1. 分类结果必须能反映题目真实来源，而不是只根据省份或岗位名称粗略归类。
2. 分类层级应支持全真模拟按真实套题、真实考试类型、真实岗位体系展示。
3. 定向备面、智能推荐、题库筛选、全真模拟选卷等功能应基于真实题库数据，不应让无题库地区或无题库岗位展示伪造的通用内容。
4. 题型维度与考试分类必须分离。例如“综合分析、组织管理、应急应变、人际关系、岗位认知、情景模拟”是题目能力维度，不是考试大类。
5. 对无法确认的分类，不要强行猜测，应标记为“待确认/需人工复核”。

## 二、统一分类层级

推荐使用如下统一层级理解所有题目和套题：

```text
一级：考试大类
  二级：地区 / 系统 / 招录类型
    三级：单位 / 岗位类别 / 专业方向
      四级：面试模式 / 题型结构 / 题量时间 / 具体套题
```

示例：

```text
国家公务员考试
  中央国家行政机关
    税务系统
      结构化小组 / 每套题若干题 / 指定时间

省级公务员考试
  江苏省
    A类综合管理岗
      4题 / 5分钟读题 + 15分钟答题 / 套题

医疗卫生面试
  北京市
    医师岗
      结构化 + 专业答辩 + 病例分析

银行招考面试
  江苏省
    国有银行 / 股份制银行 / 城商行 / 农商行
      结构化 + 专业知识
```

## 三、核心分类原则

### 1. 来源优先

分类时应优先使用题目或套题的明确来源信息：

1. 文档标题、套题标题、题目前置标题。
2. 题目已有元数据，例如省份、年份、日期、系统、岗位、批次、套题名。
3. 题干中明确出现的考试系统或岗位信息。
4. 文件名中的来源信息。
5. 最后才使用关键词推断。

不得只因题目文件来自某省，就把所有题目都归入该省所有岗位类别。

### 2. 套题优先于单题

如果题目属于真实考试套题，应先识别套题，再继承套题元数据。

例如：

```text
2025年7月5日江苏省连云港市连云区事业单位面试题
第1题 ...
第2题 ...
第3题 ...
```

三道题应共享同一个套题名称、考试日期、省份、地区、招录类型和面试规则；每题再单独记录题号、题型、分值、采分点。

### 3. 不做虚假兜底

当某个省份、系统或岗位没有题库数据时，应返回“暂无足够题库数据”或标记待补充，不得回退展示其他省份或通用岗位的分析结果。

错误示例：

```text
上海市没有题库，却展示与江苏、安徽相同的重点分析。
```

正确示例：

```text
上海市 / 综合管理岗：暂无足够题库数据，建议补充真题后再生成重点分析。
```

### 4. 考试体系与题型维度分离

分类逻辑中至少要分开两类信息：

```text
考试分类：国考、省考、事业单位、银行招考、医疗卫生、法检岗位等。
题型维度：综合分析、组织管理、应急应变、人际关系、岗位认知、情景模拟等。
```

一题可以同时属于：

```text
考试分类：省级公务员考试 / 江苏省 / A类综合管理岗
题型维度：综合分析
```

但不能把“综合分析”当作“考试分类”的下级，也不能把“江苏省”当作题型。

### 5. 地区、系统、岗位、面试形式分开记录

不得把以下概念混成一个字段：

```text
地区：江苏省、广东省、北京市、连云港市等。
系统：税务、海关、铁路公安、金融监管、法院、检察院、医疗卫生、银行等。
岗位：A类综合管理岗、医师岗、护理岗、书记员、行政岗等。
面试形式：结构化、结构化小组、结构化+追问、结构化+视频、专业答辩、实操考核等。
```

```text

中纪委

税务系统

铁路公安

金融监管系统
国家统计局
中国气象局
证监会
银保监会
国家知识产权局
```

四级分类主要记录面试形式和规则：

```text
结构化
结构化小组
结构化 + 追问
结构化 + 视频

全面谈
每天2套题

```

识别原则：

1. 出现“税务系统、海关系统”等系统名时，应优先归入对应系统，而不是泛化为“中央国家行政机关”。
2. 出现“结构化小组”“含专业题”“结构化+视频”等表述时，应单独记录为面试形式。
3. 国考中的“部门/系统”比“省份”更重要，省份只作为职位所在地或直属机构地区信息，不应覆盖系统分类。

### 2. 省级公务员考试

一级分类：

```text
省级公务员考试 / 省考
```

二级分类：

```text
具体省份或直辖市，例如江苏省、广东省、山东省、安徽省、河南省、湖北省、河北省等。
```

三级分类可按省内岗位类别、地区规则或命题类别识别：

```text
江苏省：A类 / B类 / C类，或综合管理、行政执法、乡镇等
广东省：综合岗 / 执法岗
山东省：省直 / 济南 / 烟台等地区差异
安徽省：综合管理类
河南省：县以上 / 乡镇 / 公安
湖北省：县乡 / 省直
河北省：统一面试，演讲或漫画特色
```

四级分类记录题量和时长：

```text
江苏省：4题，5分钟读题 + 15分钟答题，或20分钟包干
广东省：3题，10分钟读题 + 10分钟答题
山东省：3题，省直15分钟包干，济南7+7，烟台6+6
安徽省：3题，15分钟包干
河南省：4题，20分钟包干
湖北省：3题，县乡15分钟，省直18分钟
河北省：3题，10分钟包干
```

识别原则：

1. 省考应先识别省份，再识别省内分类。
2. 省内分类不完整时，不要强行映射到 A/B/C 类，可标记为“省内类别待确认”。
3. 时间规则属于面试规则，不属于题型。
4. 江苏全真模拟中，5分钟读题时间和15分钟答题时间应被视为两个阶段，而不是简单合并为20分钟。

### 3. 事业单位考试

一级分类：

```text
事业单位考试 / 事业单位面试
```

二级分类：

```text
省份 / 地市 / 区县 / 招录批次
```

三级分类建议：

```text
综合管理岗
专业技术岗
行政辅助岗
教育岗
医疗岗
乡镇岗
基层岗
A类 / B类 / C类 / 其他类别
```

四级分类：

```text
真实套题名称
考试日期
题号
每题分值
是否有仪态分
答题时间
读题时间
```

识别原则：

1. 事业单位题库常以真实套题为核心，必须保留中文套题名。
2. 套题名应尽量使用原文，例如“2025年7月5日江苏省连云港市连云区事业单位面试题”。
3. 如果套题含仪态分，应在套题层记录；如果没有仪态分，全真模拟提示不得强行显示仪态评分说明。
4. 如果只有“江苏事业单位真题”而没有具体日期或地区，应标记为来源不足，不要生成假套题名。

## 五、题目与套题识别规则

### 1. 套题标题识别

套题标题通常包含以下元素：

```text
年份
日期
省份
城市或区县
考试类型
岗位或批次
“面试题”“真题”“套题”等关键词
```

示例：

```text
2025年7月5日江苏省连云港市连云区事业单位面试题
2024年安徽省事业单位第二批次面试题
2020年湖南省乡镇岗事业单位面试题
```

识别要求：

1. 套题标题必须优先来自原始文档标题或题目前最近的标题行。
2. 不要将卷首目录、摘要、重复题号块误识别为新增题目。
3. 套题标题如果带有岗位、批次、地区，应拆分为结构化信息，同时保留原始标题。
4. 无法拆分时，至少保留完整中文标题。

### 2. 单题识别

每道题应识别：

```text
题号
题干
题型维度
所属套题
分值
采分点
关键词
参考答题方向
来源文档
```

识别要求：

1. 题号必须在套题内有序。
2. 若题号重复，应根据套题标题、题干正文和上下文判断是否为同一题。
3. 若文档中存在卷首摘要或重复短块，应标记为重复摘要，不应当作缺题。
4. 题目分值缺失时可标记为“未标注”，不得随意生成具体分值。

### 3. 仪态分识别

部分真实套题可能包含仪态分或举止仪表分。

处理原则：

1. 如果原文明确有仪态分，应在套题层记录仪态分，并在全真模拟说明中展示。
2. 如果原文没有仪态分，全真模拟提示应隐藏或改写相关说明，避免误导用户。
3. 如果不确定是否有仪态分，应标记为“仪态分待确认”，不要默认有仪态分。

## 六、推荐概念字段

以下字段用于描述分类结果。它们是概念字段，不要求必须按这些名称实现。

```text
examCategory：一级考试大类，例如国家公务员考试、省级公务员考试、事业单位考试、银行招考面试、医疗卫生面试、法检岗位面试。
examSubcategory：二级分类，例如中央国家行政机关、江苏省、法院系统、医疗卫生系统等。
province：省份或直辖市。
city：城市。
district：区县。
system：系统或行业，例如税务、海关、铁路公安、医疗卫生、法院、检察院、银行。
agency：具体机关、单位或银行名称。
positionType：岗位类别，例如A类综合管理岗、医师岗、护理岗、书记员、国有银行岗。
jobLevel：层级或招录层级，例如省直、县乡、乡镇、基层、中央机关、省级以下直属机构。
batch：批次，例如第二批次、补录、E类联考。
interviewFormat：面试形式，例如结构化、结构化小组、结构化+追问、结构化+视频、专业答辩。
questionType：题型维度，例如综合分析、组织管理、应急应变、人际关系、岗位认知、情景模拟。
suiteName：真实中文套题名。
suiteKey：套题稳定标识。
examDate：考试日期。
questionNo：套题内题号。
questionScore：单题分值。
suiteTotalScore：套题总分。
appearanceScore：仪态分，如无则为空。
sourceDocument：来源文档。
sourceTitleRaw：原始标题。
confidence：分类置信度，高/中/低。
reviewStatus：审核状态，例如已确认、待确认、需人工复核。
reviewReason：为什么需要复核。
```

## 七、分类优先级与冲突处理

### 1. 优先级

当多个线索冲突时，按以下顺序判断：

```text
真实套题标题
原始文档章节标题
题目已有结构化元数据
题干明确系统/岗位
文件名
关键词推断
默认待确认
```

### 2. 冲突示例

如果文件名显示“江苏事业单位”，但题干或套题标题显示“安徽省第二批次”，应优先相信套题标题，并将文件名冲突记录为复核原因。

如果题干出现“法院工作”，但套题标题为“省级公务员综合岗”，不要直接改为“法检岗位”，应标记可能涉及法治场景，分类仍以套题来源为准。

如果题干出现“金融监管”，应区分：

```text
金融监管系统：更可能属于国考系统。
银行客户营销、柜面服务、银行合规：更可能属于银行招考面试。
```

### 3. 低置信度处理

以下情况必须标记低置信度或待复核：

1. 只有省份，没有考试类型。
2. 只有岗位场景，没有招录体系。
3. 只有题型，没有来源标题。
4. 手写资料无法辨认。
5. 同一题同时命中多个考试体系。
6. 文档标题与题目标题冲突。

## 八、定向备面与智能推荐使用规则

定向备面、重点分析、智能推荐练习应只使用真实题库统计和管理员确认内容。

推荐逻辑：

1. 先按考试大类筛选。
2. 再按省份、系统、岗位类别筛选。
3. 再按题型维度统计。
4. 最后生成高频题型、热点主题、能力短板、练习建议。

禁止逻辑：

1. 无题库省份展示其他省份的重点分析。
2. 无岗位数据时展示通用岗位分析，却不提示数据不足。
3. 将管理员示例文案当作真实统计结果。
4. 将题型维度直接当作岗位分类。

如果数据不足，应输出：

```text
暂无足够题库数据
建议补充该地区/岗位真题后再生成分析
```

## 九、全真模拟使用规则

全真模拟应围绕真实套题组织，而不是随机拼题。

要求：

1. 同一套题内题目按真实题序展示。
2. 使用真实中文套题名。
3. 尽量展示考试日期、地区、岗位、批次。
4. 分值按原文记录；缺失时标记未标注。
5. 读题时间、答题时间、总时长应按真实规则记录。
6. 有仪态分则展示仪态分说明；无仪态分则隐藏或改写。
7. 如果套题元数据不足，不要生成看似真实的假名称。

## 十、管理员维护建议

后续管理员页面可允许维护以下内容：

1. 考试分类树。
2. 省份、系统、岗位、批次映射。
3. 套题元数据。
4. 题型维度。
5. 定向备面重点分析词条。
6. 无法自动识别题目的人工复核状态。

管理员编辑应只影响管理端和已发布配置，不应让普通用户看到未审核内容。

新增题目时，建议提示管理员检查：

1. 题干是否完整。
2. 是否归入正确考试大类。
3. 是否绑定真实套题或明确来源。
4. 是否填写省份、系统、岗位。
5. 是否填写题型维度。
6. 是否有采分点和关键词。
7. 是否有分值、读题时间、答题时间。
8. 是否存在仪态分。

## 十一、可直接使用的提示词

下面这段可直接作为后续修改分类逻辑时给开发者或模型的提示词：

```text
请将题库分类逻辑改为基于真实考试体系的多层级分类，不要再只依赖省份、岗位名称或题型关键词。

分类时先识别一级考试大类：国家公务员考试、省级公务员考试、事业单位考试、银行招考面试、医疗卫生面试、法检岗位面试等。然后继续识别二级地区/系统/招录类型，三级单位/岗位类别/专业方向，四级面试形式/题量时间/真实套题。

分类来源优先级为：真实套题标题 > 原始文档章节标题 > 题目已有元数据 > 题干明确系统或岗位 > 文件名 > 关键词推断 > 待人工复核。不得用省份替代考试体系，不得用题型维度替代岗位分类。

请将“综合分析、组织管理、应急应变、人际关系、岗位认知、情景模拟”等作为题型维度，而不是考试分类。考试分类、地区、系统、岗位、面试形式、题型维度必须分开保存和展示。

全真模拟必须优先按真实套题组织。每套题应保留中文真实套题名、考试日期、省份、地区、岗位、批次、题号、分值、读题时间、答题时间、是否有仪态分等信息。缺少仪态分时，不要显示默认仪态分提示；原文不明确时标记为待确认。

定向备面和重点分析必须基于真实题库统计或管理员发布内容。对于没有题库数据的省份、系统或岗位，应显示“暂无足够题库数据”，不得展示其他地区或通用模板造成伪分析。

遇到来源冲突、手写资料不清晰、字段缺失、同一题命中多个考试体系等情况，不要强行猜测，应标记低置信度、待确认或需人工复核，并记录复核原因。
```

## 十二、资料不明确之处

1. 部分 PDF 为图片型内容，无法直接抽取可复制文本，分类依据主要来自图像阅读和结构归纳。
2. 部分 JPG 为手写层级图，法检、事业单位部分细节不够清晰，应作为方向参考，不宜作为严格枚举。
3. 省级公务员图中列出的省份和规则是示例，不应作为全国省份的完整白名单。
4. 银行、医疗、法检资料中部分省份列表重复或概括为“其他20+省”，应允许后续管理员继续补充。
5. 国考部门清单可能不是完整清单，应作为当前资料中的初始分类树，不应阻止新增部门或系统。
6. 事业单位考试在不同省市差异很大，若文档只提供套题标题，应优先保留标题和来源，不要强行套入固定 A/B/C 分类。

## 十三、最终验收口径

分类逻辑完成后，应满足以下表现：

1. 江苏、安徽、湖南等已有真实题库的套题能显示真实中文套题名称。
2. 上海等无题库地区不会展示伪造重点分析。
3. 全真模拟能按真实套题进入，而不是随机拼题。
4. 同一题可以同时拥有考试分类和题型维度，两者互不覆盖。
5. 管理员能看出哪些题目分类置信度低、哪些需要人工复核。
6. 用户侧只看到确认后的分类和分析，不看到未审核或不确定的内部标记。
