## 根因和证据边界

用户录屏《屏幕录制 2026-09-20 133459.mp4》长约 53.73 秒。

- **底部突跳已复现并确认**：旧首页 MotionPresence 只负责透明度，约 140ms 后卸载内容；“近期练习”还有直接 v-if。实际测量旧版页面高度从 1919.97px 一次降到 1444.59px，scrollTop 从 1150px 被原生约束到 692px；标题相对视口位置从 74.59px 变成 532.59px。不是用淡出时长可以解决的问题。
- **录屏中的 25 秒无响应未原样复现**：基线一次真实受权操作完成导航，POST /targeted/focus 返回 HTTP 200，约 693ms。不能据此认定服务器慢、主线程卡死或某一透明层就是录屏唯一原因。
- **代码中的缺陷已确认**：旧入口先导航，重点页先等待账号权益刷新，分析忙碌状态还没建立；随后使用全屏 mask 的 showLoading。store 只有一个布尔忙碌标记，无任务隔离、主动停止和结构化错误状态；旧 finally 可能清掉新请求的 loading。接口“成功”但响应结构错误也可能进入渲染。
- 独立审查额外复现：深链白名单遗漏 subcategory/city/计时字段，济南筛选可能扩大到省；首次分类树失败却设为已加载，页面缓存阻止重试。已修复并补测试。

当前分析接口读取管理员已发布配置或真实题库统计，**不是此处调用外部大模型生成报告**；不改变作答点评的外部模型策略。

### 折叠与滚动

外层以实测的当前高度为起点，内部真实内容高度为目标，单位全部为逻辑 px。通过两组交替 CSS keyframe 名启动高度变化，避免把 nextTick 或 16ms 当作已经绘制的保证。展开完成恢复 auto，收起完成才卸载内容；padding、卡片 margin 和边框都在高度容器内。内层淡入/退出与箭头分别处理，未使用 scaleY、超大 max-height、transition:all 或逐帧 setData。

快速反向、异步内容修订、窗口尺寸变化会重新测量；编号隔离旧测量和结束回调，结束事件过滤子元素，计时兜底幂等。页面隐藏暂停动画并保留占位，恢复测量，销毁清理。现有图表为 view/条形图布局，不新增图表实例；组件暴露 remeasure，未来新增异步图片应在加载事件调用它。

新版本开发者工具测到折叠高度约 491→120→24→3→0px 的连续中间态，页面与滚动位置同步渐变；结束不再一次移除整块布局。**本轮不增加占位保护或主动滚动补偿**，没有同时叠加多个滚动协调器。不同节点的查询有回调间隔，这些数字是采样，不是逐帧性能指标。

统一参数：高度 280ms，内容进入 200ms、退出 140ms、4px 位移，箭头 200ms；扫描 2100ms、浮动 3600ms/3px，缓动沿用 cubic-bezier(0.22,1,0.36,1)。减弱/关闭模式不播放高度和装饰循环，直接收敛最终布局。

### 分析任务与结果

状态为 idle / loading / success / error / timeout / cancelled。受理时立即设置局部忙碌，只有分析提交去重，导航保持可用。同一个规范化参数复用进行中的任务；方向变化取消旧等待并清除不匹配结果。结果标签来自发起时的参数快照，旧成功/失败/finally 都不能覆盖新任务。

网络、HTTP、业务、解析、超时有原位反馈与重试；同参数上次有效结果保留。10s 后补充“这次分析需要一点时间”，不伪造阶段或百分比；接口仍使用 30s 超时，并有逻辑层截止兜底。停止或离页清理所属计时器、观察器和前端连接，文案明确服务端可能仍在处理，不承诺服务端任务取消，也不新增后台任务调度。

加载和结果使用同一高度容器，收到真实完整响应就展示，不逐字伪流式、不故意延迟完成。纸张动画同时受页面可见、loading 和观察器可见性约束；离屏测试实测 transform 停止变化，回到可见才能播放。原生 computedStyle 对 CSS 变量驱动的 animation-play-state 可能返回静态声明，验收同时检查播放类与实际 transform，不能只据一个字符串下结论。
