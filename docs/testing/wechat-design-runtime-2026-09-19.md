# 2026-09-19 微信原生界面与设计对齐

## 根因及修复范围

微信开发者工具打开的是 `D:\项目\考公项目\mp-weixin-prod`。修复前的 WXML、页面 WXSS 和 app.js 与 WSL 最新生产构建一致，因此不是用户导入了旧包。

实际发现三类问题：

1. 四个页面使用 `<style src="@/styles/learner.css">`，当前 uni-app 小程序编译器没有输出主题 WXSS，只生成空的 `learner.js`。改为 App.vue 中的 CSS `@import`，四页通过 `.learner-page` 范围共享主题，不影响其他页面。
2. Ant Design 的 inline SVG 缺少独立图片所需的 SVG 命名空间。导出器补齐 `xmlns`、尺寸，保留 viewBox 和路径，移除空样式节点；16 个图标随包离线加载。
3. RoomActions 组件没有自己的 WXSS，而布局写在父页面的 scoped 样式里。微信组件隔离导致退出/提交按钮上下堆叠。布局移入组件自身，同时修正旧考场底色和结果原文标题的对齐。

首页按 Pencil 设计恢复两行标题、麦克风图标和三个大尺寸快捷入口，统计移到近期练习区域但不删除数据功能。准备页优先展示练习模式，录音/录像独立分区；保留题量、地区、题型、年份、套卷选择与权益判断。

未修改管理员后台、支付、登录策略、采集/后台提交/计时逻辑、评分模型或费用策略。文字作答保持关闭，`LOCAL_REFERENCE_SCORING=false` 不变。既有 `.pen` 设计稿保留，修复的是实现与设计的偏差。
