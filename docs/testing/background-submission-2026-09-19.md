## 重点边界

1. 提交固定本题用时，等待本机录音交付后换题；上传、转写、点评和使用时长上报不阻塞下一题。
2. PC 截止时间计时保留小数秒；微信延迟 tick 补扣实际时间；江苏 5+15 切题不重置。
3. 重复提交复用同一任务；迟到回调不覆盖下一题；失败原文和录音保留；重试不重复已完成的上传/转写。
4. 评分响应缺失、空白、非数值、非有限分数转为可重试失败；真实数值 0 正常显示。
5. 完成请求先固定结束时间，任务结束后刷新同一场汇总；结果页不等待网络才打开。
6. 新场开始失败不清空旧场；成功后旧场待处理答案仍可见、可重试。部分失败时整场媒体保留，全部完成后下一次成功开考释放媒体引用。
7. 退出、换账号或重置使旧任务失效，上传/ASR/点评各阶段与自动转写重试不使用下一账号身份。
8. 后台进度仅反映真实阶段，不虚构百分比；失败步骤由已确认上传和已有原文决定。

## 发布与未覆盖范围

按功能分段提交后，用 `scripts/deploy_verified_release.sh` 的 prepare、web 阶段发布电脑端及服务器小程序包；后端源代码未改，不运行 backend 阶段、不重启后端。发布时核对远端 REVISION、健康接口和公开页面静态资源，实际版本与发布结果写入 Windows 交付包的 `release-info.json`。

当前“后台”仍为客户端会话内任务，不承诺刷新、关闭页面或清理微信后继续上传。外部点评模型推理时间没有被本轮测试证明缩短；改善的是前台不再被迫等待，费用与模型品质不降级。

未实测真实手机麦克风/摄像头、微信原生生命周期及新的付费模型请求。小程序服务器产物同步不等于微信公众平台发布，仍需开发者工具上传、真机体验和发布流程。已测过且本轮未变更的后端业务测试不重复运行。
