# 2026-09-19 功能验收修复记录

依据 Windows 验收清单逐项核对；原文件保持不变，未测试项不视为通过。

## 第一批：登录会话与账号隔离

- 用户确认规则：电脑与微信可同时使用，同类客户端的新登录替换旧会话；错误密码不撤销有效会话。
- 新增 `user_login_sessions` 表保存两类会话标识；由现有启动建表流程补齐。旧 token 在首次新登录前继续有效。
- `/token` 增加可选 `client_type=web|wechat`，默认 web；小程序密码登录和微信快捷登录均使用 wechat。
- 登录失败仅显示中文原因，不作为会话过期跳转；受保护请求的 401 清空账号状态并引导重新登录。
- 账号切换清理内存中的考试、历史、训练、权益和收藏状态；旧 token 发出的迟到请求不写入新账号页面。
- 训练进度、权益和偏好缓存按账号区分；不认领来源不明的旧共享缓存，不删除旧缓存文件。
- 管理员权限、支付核验和外部模型评分配置保持原样，`LOCAL_REFERENCE_SCORING=false`。

验证：后端 106 项通过；两端 Node 逻辑测试 14 项通过。测试用短 JWT 密钥有警告，不是生产配置。客户端生产构建另行验证；以上不等于微信真机验收。
