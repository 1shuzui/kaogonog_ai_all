# 题库分类口径

## 必须分开的概念

| 概念 | 用途 | 示例 |
| --- | --- | --- |
| 考试体系 `examCategory` | 真实题源主分类 | 国家公务员考试、省级公务员考试、事业单位考试 |
| 二级分类 `examSubcategory` | 地区、中央系统或来源层级 | 江苏省、安徽省、中央国家行政机关 |
| 地区/系统/岗位 | 筛选和展示真实来源 | 盐城市、监狱系统、税务系统、医师岗 |
| 面试形式 `interviewFormat` | 决定提示和部分时间规则 | 结构化面试、结构化小组、结构化+专业题 |
| 题型分类 `questionTypeCategory` | 专项训练和高频题型统计 | 综合分析、组织管理、应急应变 |
| 能力维度 | 评分、薄弱维度和能力概览 | 行政思维、实务落地、逻辑结构 |

## 分类来源优先级

1. 真实套题标题。
2. 原始文档章节标题。
3. 题目已有元数据。
4. 题干中明确的系统或岗位。
5. 文件名。
6. 关键词推断。
7. 待人工复核。

## 重要约束

- 不得用省份替代考试体系。
- 不得用题型维度替代岗位分类。
- 银行、医疗卫生、法检书记员可以是特色展示入口，但不能抢掉题目的真实题源主分类。
- 江苏事业单位仍归 `事业单位考试 / 江苏省`，即使题目涉及医疗、市场监管、税务等岗位。
- 湖南监狱、税务补录仍归 `省级公务员考试 / 湖南省`，系统字段单独记录。
- 没有题库数据的定向备面方向，普通用户应看到“暂无足够题库数据”，不能展示伪分析。

## 能力维度与训练分类

能力维度只用于评分和考生能力分析：

- 行政思维
- 实务落地
- 逻辑结构
- 语言表达
- 综合分析
- 应急应变

训练分类只用于题型筛选和专项训练：

- 综合分析
- 组织管理
- 应急应变
- 人际沟通
- 情景模拟
- 岗位认知
