# ADR-001: 本地项目按“源码留仓库、资料外置索引化”整理

## Status
Accepted

## Date
2026-06-09

## Context

项目根目录长期混有源码、题库 Word、抽取文本、指导截图、回归报告、支付截图、密钥和运行缓存。后续维护时，人工和 AI 都需要更快判断哪些是运行源码、哪些是资料、哪些是历史报告。

## Decision

- 不重排源码结构。
- 根目录收口为代码项目、文档、报告、数据索引和必要配置说明。
- 大量历史资料迁到 `/home/quyu/doc_kaogong`。
- 仓库内用 `docs/`、`data/question-bank/` 和 `reports/README.md` 记录索引和恢复方式。

## Consequences

- 仓库更适合开发和交接。
- 题库源文件和旧报告仍可通过外部归档找回。
- 新机器拉仓库后不会自动拥有真实 `.env`、支付证书和题库原始 Word，需要按文档恢复。
